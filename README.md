# MeetMark releases

Windows x64 NSIS installers and automatic-update metadata for MeetMark.

Install the first updater-enabled build manually from the published Releases page. Installed builds then check for stable updates automatically and download them in the background. Choose **Restart and install** in Settings or the tray after finishing capture and saving your work.

The development preview does not install updates. Application source is maintained separately.

No updater-enabled release has been published yet. Release artifacts appear only after build, version, checksum and optional signing validation.
